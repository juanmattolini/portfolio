# Logos de herramientas

SVG de [Simple Icons](https://simpleicons.org) 16.35.0 (licencia CC0). Cada logo es marca registrada de su dueño y se usa solo para indicar con qué herramientas trabajo.

En `index.html` se pintan con CSS (`mask`) usando el color oficial de cada marca. Para sumar uno: copiar `icons/<slug>.svg` del paquete `simple-icons` a esta carpeta y agregar un `<li class="tool tool-<slug>">` en la sección "Herramientas" con su color (`--c`).
